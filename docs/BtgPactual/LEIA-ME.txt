LEIAME - Kit Implantação CNAB

Este kit contém arquivos que auxiliam a configuração do CNAB no formato Febraban assim 
como a montagem de boletos e cálculo do código de barras.

# Máscara boleto BTG PACTUAL.pdf
Exemplo de boleto gerado pelo BTG

# Regra de Cálculo do Código de Barras e Linha Digitavel.pdf
Explica todas as regras de cálculo para gerar linha digitável e código de barras compatíveis com sistema de
geração de boleto do BTG.

# Tradutor Linha Digitável BTG.xlsx
Utilize esse arquivo para validar ou comparar uma linha digitável gerada fora do sistema BTG. 

# Exemplos de CNAB .ret e .rem
Arquivos CNAB de exemplo para comparação de formatação.
